### 🔭 What I'm working on

Backend engineer at **iAcloud (주식회사 아이에이클라우드)**, building **[CloudiA](https://iacloud.kr)**
([product manual](https://ia-cloud.gitbook.io/cloudia-manual)) — an enterprise private-cloud (IaaS)
platform on Linux kernel virtualization (QEMU/KVM), with GPU/NPU virtualization for AI workloads.

I own the **VM Management System core engine**:

- 🖥️ **VM provisioning & lifecycle** — designed the provisioning backbone from 0→1
- 🔁 **Live migration tuning** — cut network downtime from ~20s to 1–2s
- 🐧 **Multi-OS cloud-init** — unified guest config across RHEL / Rocky / Debian / Ubuntu
- 🔐 **Confidential computing** — AMD SEV / SEV-ES / SEV-SNP secure VMs
- 🧩 **libvirt Domain XML builder** — typed, validated XML generation for QEMU/KVM
- 🌍 **Terraform provider** — declarative management of the platform (Go)

> ℹ️ Most of this lives in **private repos**, so my public GitHub is light on it.
> Happy to walk through the architecture and trade-offs in detail.
